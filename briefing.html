Reading an approach chart

Commercial approach charts share one layout: heading, briefing strip, plan view, profile view and minimums, always in the same places. This training chart follows that layout so you learn where to look on a real plate. The airport, procedure and numbers are fictional. Tap a number on the chart.

Method

How to brief an approach plate: TSADMM

Work through the plate from the top down, in the same order every time. Read the numbers off the chart, say them out loud, and set them as you go. A briefing takes about a minute. If it takes five, you are reading the chart to yourself instead of making a plan.

TSADMM: Threats, Setup, Arrival, Descent, Minimums, Missed approach. Threats come first so the rest of the briefing is built around them. What matters is that the order is fixed and that you end with the missed approach. Set the minima on the bug and the missed-approach altitude in the preselect while you brief them.
